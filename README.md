# Telegram Post Parser

Сервис следит за заданными Telegram-каналами/группами, скачивает все вложения нового
поста, передает текст и (при наличии vision-модели) изображения в LLM, отсеивает
рекламу и дубли, удаляет упоминания источника и сохраняет переформулированный результат. Для
каждого источника поддерживается отдельное дополнение к промпту. При указании
`telegram.destination` результат также публикуется в ваш канал.

> Используйте сервис только для контента, который вы вправе читать и
> переиспользовать. Автоматическое перефразирование само по себе не отменяет
> авторские права и требования об указании источника.

## WEB-интерфейс (ветка `react`)

Ветка `react` содержит локальную React-панель со следующими разделами:

- **Управление** — запуск и остановка мониторинга, состояние процесса, живой
  терминал и поле ввода для номера телефона, кода Telegram и пароля 2FA;
- **Настройки** — Telegram, LLM-провайдер, модель, хранилище и лимит файлов;
- **Источники** — добавление, отключение и удаление каналов, индивидуальный промпт.

Для запуска щёлкните правой кнопкой по `start-web.ps1` и выберите «Выполнить с
помощью PowerShell» либо выполните:

```powershell
.\start-web.ps1
```

Скрипт при необходимости установит WEB-зависимости, создаст `config.yml`, запустит
локальный сервер и откроет <http://127.0.0.1:8765>. Node.js не требуется: React
поставляется вместе с проектом. Другой порт можно задать так:

```powershell
.\start-web.ps1 -Port 9000
```

Панель намеренно доступна только на `127.0.0.1`. Не публикуйте её в интернет:
она управляет процессом и имеет доступ к локальной конфигурации. Секреты при
загрузке настроек маскируются; если оставить маску без изменений, сохранённый ключ
не перезаписывается.

## Возможности

- произвольное количество источников в YAML;
- индивидуальный промпт и флаг включения для каждого источника;
- OpenAI-совместимые провайдеры, включая DeepSeek;
- LLM-фильтрация рекламы и смысловых дублей за настраиваемый период;
- отдельная vision-модель для анализа изображений;
- поддержка одиночных фотографий и Telegram-альбомов;
- пересылка видео, аудио, голосовых сообщений, архивов и любых документов;
- локальный JSON-архив результатов и SQLite-защита от дублей;
- необязательная автоматическая публикация в целевой канал;
- ошибки одного поста журналируются и не останавливают монитор.

## Установка

Нужен Python 3.11 или новее. Создайте Telegram API-приложение на
<https://my.telegram.org>, чтобы получить `api_id` и `api_hash`. Это не Bot Token:
монитор работает от пользовательской сессии, поскольку боты обычно не могут
читать произвольные чужие каналы.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
Copy-Item config.example.yml config.yml
```

На Linux/macOS активация: `source .venv/bin/activate`, копирование:
`cp config.example.yml config.yml`.

## Настройка

Отредактируйте `config.yml`:

```yaml
telegram:
  api_id: 12345678
  api_hash: "ваш_api_hash"
  session: "tg_monitor"
  destination: "@my_destination" # или null — только сохранять JSON

llm:
  api_key: "ваш_deepseek_api_key"
  base_url: "https://api.deepseek.com"
  model: "deepseek-chat"
  vision_model: null
  temperature: 0.3
  max_tokens: 1800

analysis:
  enabled: true
  history_hours: 24 # глубина истории для поиска дублей

storage:
  database: "state.db"
  output_dir: "output"
  max_post_download_mb: 100 # общий лимит вложений одного поста/альбома

sources:
  - chat: "https://t.me/source_one"
    enabled: true
    prompt_addition: "Пиши нейтрально и сохрани все числа."
  - chat: "@source_two"
    enabled: true
    prompt_addition: "Сократи до трех абзацев."
```

Секреты можно брать из переменных окружения: например, укажите
`api_key: "${DEEPSEEK_API_KEY}"`, предварительно задав переменную.

Перед рерайтом LLM сравнивает новый материал с исходными текстами уже
опубликованных постов за последние `analysis.history_hours` часов и проверяет
рекламные признаки. Полный смысловой дубль и реклама помечаются обработанными в
SQLite, но не сохраняются в JSON и не публикуются. Продолжение или обновление с
существенными новыми фактами не считается дублем. Проверку можно отключить через
`analysis.enabled: false`.

Если сумма размеров всех файлов поста или альбома превышает
`storage.max_post_download_mb`, весь пост пропускается: файлы не отправляются в
LLM и целевой канал. Когда Telegram не сообщил размер заранее, лимит повторно
проверяется после скачивания, а частично загруженные файлы удаляются.

DeepSeek Chat на момент настройки является текстовой моделью, поэтому при
`vision_model: null` изображения сохраняются и пересылаются в целевой канал, но
не отправляются в LLM. Чтобы анализировать их содержимое, укажите модель с
поддержкой изображений у выбранного OpenAI-совместимого провайдера и при
необходимости измените `base_url`, `api_key` и `vision_model`.

## Запуск

```powershell
tg-post-parser --config config.yml
```

Либо без установленной консольной команды:

```powershell
python -m tg_post_parser.cli --config config.yml
```

При первом запуске Telethon попросит номер телефона, код из Telegram и пароль
двухфакторной аутентификации. Затем рядом появится файл сессии; не публикуйте его.
Новые результаты находятся в `output/*.json`, все вложения — в `output/media/`, а уже
обработанные ID — в `state.db`. Остановка: `Ctrl+C`.

Аккаунт должен состоять в закрытой группе, если источник закрытый. Для публикации
в `destination` аккаунт должен иметь соответствующие права.

## Тесты

```powershell
python -m pytest
```

Тесты полностью локальны: Telegram и реальный LLM API не вызываются.

## Ограничения

- изображения анализируются vision-моделью; остальные файлы и документы без
  изменения пересылаются в целевой канал, но их содержимое не анализируется LLM;
- очень длинная подпись к нескольким фото может превысить лимит Telegram при
  автопубликации — в таком случае ошибка останется в журнале, а JSON сохранится;
- изменение промпта не переобрабатывает старые записи автоматически; удалите
  конкретную запись из SQLite только если осознанно хотите повторную обработку.
